# Engagement pack template

Copy this folder to `engagements/<slug>/` via `ingest-context` only after repository distribution of a sanitized derivative is explicitly approved at the sensitivity and distribution gate. Fill from evidence. Leave unused judgment files empty.

- `CONTEXT.md` — terms and allowed assertions, cited
- `sources.md` — source IDs, sanitized locators or hashes, sensitivity, and distribution decisions
- `engagement.md` — who, done-looks-like, constraints, open questions
- `context/` — ICP, personas, exclusions, rubric *when the drop contains them*
- `raw/` — ignored local working material; never a tracked copy of private source data

Tracked files contain only minimum-necessary sanitized derivatives. Quotes and paraphrases must not reintroduce personal contacts, compensation or commercial terms, identity or background-check information, credentials, health or financial data, or other restricted values.
