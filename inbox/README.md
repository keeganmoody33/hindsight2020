# Inbox

Put **local-only drops** here: briefs, transcripts, notes, exports. Repository ignore rules keep drops out of version control; this README remains tracked as guidance. Version control is distribution, not per-file access control.

Ask the agent to **ingest** when a drop is ready. Ingest first applies the sensitivity and distribution gate in [`system/privacy-and-distribution.md`](../system/privacy-and-distribution.md). Only an explicitly approved, minimum-necessary sanitized derivative may be written to tracked pack files. Private raw material is never copied into the repository.

If a drop is already tracked, published, or not ignored, stop and escalate instead of ingesting or committing it.
